## ✨ Features

- 📷 **Camera Capture** — Use your device camera
- ✂️ **Auto-Crop** — Automatically detects document edges
- ✨ **Image Enhancement** — Improves contrast and brightness
- 🔍 **OCR Text Extraction** — Extract text using Tesseract.js
- 💾 **Multiple Formats** — Download as PNG, JPEG, PDF, or Text
- 🔒 **100% Private** — Everything stays on your device
- 📱 **Mobile Friendly** — Works on phones, tablets, and desktops
- ⚡ **No Uploads** — No data ever leaves your device
- 🚀 **Instant** — No network latency

---

## 🚀 Quick Start

1. Open `index.html` in a modern browser
2. Click "Start Scanning"
3. Allow camera permissions
4. Position your document
5. Click "Scan Document"
6. Download in your preferred format
